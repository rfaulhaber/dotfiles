#+TITLE: Atlas

~atlas~ is my home file server. It runs a minimal, non-GUI installation of this NixOS configuration.

~atlas~ uses zfs to manage file storage for all of the services I host. It is also a low-compute service host in itself. The services used by ~atlas~ are specified in ~./oci.nix~, which specify the OCI modules defined in ~nix/modules/linux/oci~.

Each OCI module can specify a ZFS dataset to utilize, which will be created and managed on ~atlas~. ~atlas~'s main data pool uses raidz2 by default.
