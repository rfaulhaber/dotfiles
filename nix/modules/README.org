#+title: nix modules

The root of my nix modules.

Modules adhere to the following design guidelines:

- Modules are more specific instances of generic nix modules, with my preferences encoded. Host-specific configurations are exposed via options
- A module shouldn't just be a front-end for a nix module
- Platform-specific modules live under the ~darwin/~ and ~linux/~ directories respectively
- Platform-agnostic programs live under ~programs/~
- Things that run daemons live under ~services/~ (this distinction is somewhat arbitrary)
